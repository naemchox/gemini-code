ลบแชท Gemini ที่ `/gcode` สร้างขึ้น **เฉพาะจากแชท Claude นี้** ห้ามแตะแชท Gemini อื่นเด็ดขาด

## วิธีทำ

1. ดูรายการแชทของแชทนี้:

   ```bash
   gcode --session "$CLAUDE_CODE_SESSION_ID" --list-chats
   ```

   ได้ JSON เป็น array ของ `{id, prompts, created_at, updated_at}` เรียงตามลำดับที่สร้าง
   `prompts[0]` คือคำสั่งแรกที่ทำให้แชทนั้นเกิดขึ้น ใช้เป็นชื่อในเมนู
2. **ถ้า array ว่าง**: บอกผู้ใช้ว่าแชทนี้ยังไม่ได้สร้างแชท Gemini ไว้ ไม่มีอะไรต้องลบ แล้วจบ
3. **ถ้ามี 1 แชท**: ถามยืนยันก่อนเสมอด้วย AskUserQuestion โดยแสดง `prompts[0]` และ `id`
   ให้เลือก "ลบ" หรือ "ไม่ลบ"
4. **ถ้ามี 2–3 แชท**: ใช้ AskUserQuestion แบบ `multiSelect: true` โดย label ของแต่ละตัวเลือกคือ
   `prompts[0]` ของแชทนั้น (description ใส่ `id` + จำนวนข้อความ) และเพิ่มตัวเลือกสุดท้าย "ไม่ลบอะไรเลย"
5. **ถ้ามี 4 แชทขึ้นไป**: แสดงเป็นรายการเลขลำดับ (เลข. `prompts[0]` — `id`) แล้วถามเป็นข้อความว่า
   จะลบหมายเลขไหนบ้าง (ตอบ "ทั้งหมด" หรือ "ไม่ลบ" ได้) แล้วรอคำตอบก่อนลบ
6. ลบเฉพาะ id ที่ผู้ใช้เลือก ด้วยคำสั่งเดียว:

   ```bash
   gcode --session "$CLAUDE_CODE_SESSION_ID" --delete <id1> <id2> ...
   ```

   คำสั่งนี้เว้นจังหวะระหว่างการลบแต่ละแชทให้เองแล้ว (timeout 600000 ms)
   ห้ามส่ง id ที่ไม่ได้อยู่ในผลของ `--list-chats` เด็ดขาด
7. รายงานว่าลบอันไหนสำเร็จ อันไหนไม่สำเร็จ และเหลืออะไรอยู่บ้าง
   ถ้ามีอันที่ลบไม่สำเร็จ อย่าลองซ้ำเอง ให้ถามผู้ใช้ก่อน

## ข้อควรระวัง

- เจอ `google.com/sorry` หรือ CAPTCHA: หยุดทันที แจ้งผู้ใช้ให้ยืนยันตัวตนเอง
- แชทที่ถูกลบไปแล้วจะหายจาก log อัตโนมัติ ถ้า `--list-chats` ยังแสดงอยู่แปลว่ายังไม่ถูกลบ
