ส่ง **เฉพาะคำสั่งนี้** ไปให้ Gemini ห้ามตอบเองและห้ามทำงานนี้เองด้วยเครื่องมืออื่น

คำสั่งของผู้ใช้: $ARGUMENTS

## วิธีทำ

1. ถ้าในคำสั่งมี `--new` ให้ตัดคำนั้นออกจาก prompt แล้ว**ไม่ต้องใส่ `-c`** (เปิดแชท Gemini ใหม่)
   ถ้าไม่มี ให้ใส่ `-c` เพื่อคุยต่อในแชท Gemini เดิมของแชท Claude นี้
2. รัน (timeout 600000 ms เพราะการสร้างรูปใช้เวลานาน):

   ```bash
   gcode --session "$CLAUDE_CODE_SESSION_ID" -c "<prompt ที่ผู้ใช้พิมพ์>"
   ```

   - `--session "$CLAUDE_CODE_SESSION_ID"` สำคัญมาก อย่าลืม เพราะเป็นตัวผูกแชท Gemini
     เข้ากับแชท Claude นี้ ทำให้ `/gcodeclose` ลบได้ถูกอัน และทำให้ `-c` คุยต่อได้ถูกแชท
   - ใส่ prompt เป็น argument เดียวในเครื่องหมายคำพูด ตามที่ผู้ใช้พิมพ์ ห้ามแปลหรือเรียบเรียงใหม่
   - รันครั้งเดียวต่อหนึ่ง `/gcode` ถ้าพลาดให้อ่าน error ก่อน อย่ารันซ้ำรัวๆ (กฎใน StartUp/CLI/CLAUDE.md)
3. แสดงคำตอบที่ Gemini ตอบกลับมาให้ผู้ใช้ โดยคงเนื้อหาไว้ตามเดิม ไม่ต้องสรุปย่อ
   ถ้ามีไฟล์รูปถูกบันทึก ให้บอก path ของไฟล์ (gcode บันทึกลง directory ที่รันอยู่)
4. ปิดท้ายด้วยบรรทัดเดียวว่าใช้ `/gcodeclose` เพื่อลบแชท Gemini ที่สร้างจากแชทนี้

## ถ้ามีปัญหา

- เจอ `google.com/sorry` หรือ CAPTCHA: **หยุดทันที** แจ้งผู้ใช้ให้ยืนยันตัวตนเองใน Chrome ห้ามรันซ้ำ
- `ยังไม่ได้ลงชื่อเข้าใช้ Google`: แจ้งผู้ใช้ให้ล็อกอินในหน้าต่าง Chrome ของ gcode
- คำสั่งค้างเกิน timeout: แจ้งผู้ใช้ และบอกว่าดูหน้าจอจริงได้ด้วยการรัน `gcode` แล้วพิมพ์ `/open`
