# Gemini Code (v0.1)

ผู้ช่วยเขียนโค้ดใน terminal แบบ Claude Code ใช้ Gemini API (key ฟรีจาก Google AI Studio)
อ่าน/ค้นหา/แก้ไฟล์ และรันคำสั่งได้ โดยจะถามก่อนทุกครั้งที่แก้ไฟล์หรือรันคำสั่ง

## ติดตั้ง

```bash
cd "/Users/wsongaksorn/Library/CloudStorage/GoogleDrive-wannuwat2001@gmail.com/My Drive/AI plus/Work/Websites/StartUp/CLI"
./setup.sh
```

1. สร้าง API key ฟรีที่ https://aistudio.google.com/apikey
2. ใส่ใน `.env` ของโฟลเดอร์นี้: `GEMINI_API_KEY=...`
3. เพิ่ม alias ที่ setup.sh แสดงไว้ใน `~/.zshrc` แล้วเปิด terminal ใหม่

> venv ถูกสร้างที่ `~/.venvs/gemini-code` (นอก Google Drive) เพื่อไม่ให้ Drive ต้อง sync ไฟล์ไลบรารีนับพันไฟล์

## ใช้งาน

```bash
cd ~/some-project      # agent จะทำงานในโฟลเดอร์ที่คุณเรียกใช้
gcode                  # โหมดคุยต่อเนื่อง
gcode "อธิบายโปรเจกต์นี้"  # ทำงานเดียวแล้วออก
gcode -m gemini-2.5-flash  # เลือกโมเดล
gcode --yolo           # อนุมัติทุกอย่างอัตโนมัติ (ระวัง)
```

คำสั่งในแอป: `/help` `/clear` `/model [ชื่อ]` `/models` `/usage` `/exit`

`/usage` แสดงจำนวนคำขอและ token ของเซสชันนี้ และจำนวนคำขอของวันนี้แยกตามโมเดล
(บันทึกใน `~/.gemini-code/usage.json` นับวันตามเวลาแปซิฟิกซึ่งเป็นเวลาที่โควตารายวันรีเซ็ต
คือประมาณ 14:00–15:00 น. เวลาไทย) โควตาที่เหลือจริงดูได้ที่ https://aistudio.google.com/usage

**โควตาที่เหลือ** = เพดาน − ที่ใช้ไป เพราะ Google ไม่มี API บอกโควตาที่เหลือ
- เพดานโดยประมาณอยู่ใน `limits.json` (แก้ให้ตรงกับหน้า Rate limits ใน AI Studio ได้)
- เมื่อเจอ error 429 แอปจะอ่านเพดานจริงที่ Google แนบมา บันทึกใน `~/.gemini-code/limits.json` และใช้แทนค่าประมาณ
เวลาถูกถามอนุญาต: `y` = ครั้งนี้, `a` = อนุญาต tool นี้ตลอดเซสชัน, `n` = ไม่ (บอกเหตุผลให้ Gemini ได้)

ถ้าโปรเจกต์มีไฟล์ `GEMINI.md` หรือ `AGENTS.md` จะถูกโหลดเป็นคำสั่งเพิ่มเติมให้ agent อัตโนมัติ

## เครื่องมือที่ Gemini ใช้ได้

| tool | ทำอะไร | ต้องขออนุญาต |
|---|---|---|
| `read_file` | อ่านไฟล์ (มีเลขบรรทัด) | ไม่ |
| `list_dir` | ดูไฟล์ในโฟลเดอร์ | ไม่ |
| `glob_files` | หาไฟล์ตาม pattern เช่น `**/*.py` | ไม่ |
| `grep` | ค้นหาข้อความด้วย regex | ไม่ |
| `write_file` | สร้าง/เขียนทับไฟล์ (แสดง diff ก่อน) | ใช่ |
| `edit_file` | แทนที่ข้อความในไฟล์ (แสดง diff ก่อน) | ใช่ |
| `run_shell` | รันคำสั่ง shell | ใช่ |

## โครงสร้างโค้ด

```
gemini_code/
  __main__.py   จุดเริ่ม: argument, หน้าจอรับคำสั่ง, slash commands
  agent.py      วนรอบ: ส่งบทสนทนา → Gemini ขอเรียก tool → ขออนุญาต → รัน → ส่งผลกลับ
  tools.py      นิยามและโค้ดของแต่ละ tool (เพิ่ม tool ใหม่ได้ที่นี่)
gcode           launcher เรียกได้จากทุกโฟลเดอร์
setup.sh        ติดตั้ง venv + dependencies
```

## ข้อจำกัดของ v0.1 / สิ่งที่ควรรู้

- **โควตาฟรีน้อย**: ประมาณ 10–15 คำขอ/นาที งานหนึ่งอาจใช้หลายรอบ ถ้าโดน 429 แอปจะรอแล้วลองใหม่ให้เอง
  ถ้าโควตารายวันหมดจะแสดง error ให้รอวันถัดไปหรือเปลี่ยนโมเดล (`/models` ดูรุ่นที่ใช้ได้)
- ข้อมูลที่ส่งผ่าน key ระดับฟรี Google อาจนำไปพัฒนาโมเดล อย่าใช้กับโค้ดที่เป็นความลับ
- ยังไม่มี: streaming คำตอบทีละคำ, บีบอัดบทสนทนาเมื่อยาวมาก (ใช้ `/clear` แทน), บันทึก/เรียกเซสชันเก่า,
  undo การแก้ไฟล์ (ใช้ git ในโปรเจกต์เป็นตัวช่วย)
- `run_shell` รันแต่ละคำสั่งใน shell ใหม่ ดังนั้น `cd` ไม่คงอยู่ข้ามคำสั่ง
