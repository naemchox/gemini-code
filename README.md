# Gemini Code (v0.2)

ใช้ Gemini ใน terminal ได้ 2 โหมด

| โหมด | คำสั่ง | ใช้อะไร | ทำอะไรได้ |
|---|---|---|---|
| **เว็บ** (ค่าเริ่มต้น) | `gcode` | บัญชี Gemini Plus ผ่าน gemini.google.com | แชท, ดึงคำตอบมาแสดง, เซฟรูปที่ Gemini สร้าง |
| **API** | `gcode --api` | API key ฟรีจาก AI Studio | agent อ่าน/แก้ไฟล์ และรันคำสั่งได้แบบ Claude Code |

## ติดตั้ง

```bash
git clone https://github.com/wannuwat-s/gemini-code.git
cd gemini-code
./setup.sh
```

1. เปิด terminal ใหม่ (หรือ `source ~/.zshrc`) แล้วรัน `gcode` หนึ่งครั้ง
   ลงชื่อเข้าใช้ Google ในหน้าต่าง Chrome ที่เปิดขึ้นมา
2. (โหมด API เท่านั้น) สร้าง API key ฟรีที่ https://aistudio.google.com/apikey แล้วใส่ใน `.env`: `GEMINI_API_KEY=...`

setup.sh ทำให้ครบ: สร้าง venv, ลง dependencies, สร้าง `.env` จากตัวอย่าง, เพิ่มฟังก์ชัน `gcode` ใน
`~/.zshrc` (ใช้ในเทอร์มินัล) และลิงก์ `/gcode` `/gcodeclose` เข้า `~/.claude/commands/` (ใช้ใน Claude Code)
ทั้งสองอย่างจะ**ข้ามให้เอง ไม่ทับของเดิม** ถ้ามี `gcode` อยู่ใน `~/.zshrc` หรือมีไฟล์ชื่อเดียวกันใน
`~/.claude/commands/` อยู่แล้ว — กรณีนั้น setup.sh จะบอกว่าต้องเติมอะไรเอง

รัน `./setup.sh` ซ้ำได้เสมอ ถ้าย้ายโฟลเดอร์ repo มันจะเขียนทับบล็อกเดิมใน `~/.zshrc` ให้ชี้ที่ใหม่
(ใช้ shell อื่น: `GCODE_SHELL_RC=~/.bashrc ./setup.sh`)

**ต้องมี:** macOS และ Google Chrome — โหมดเว็บสั่ง Chrome จริงผ่าน CDP และใช้ AppleScript ซ่อน/แสดงหน้าต่าง
ไม่ต้องรัน `playwright install` เพราะไม่ได้ใช้ browser ที่ Playwright โหลดมา

> venv ถูกสร้างที่ `~/.venvs/gemini-code` (นอก Google Drive) เพื่อไม่ให้ Drive ต้อง sync ไฟล์ไลบรารีนับพันไฟล์
>
> การลงชื่อเข้าใช้เก็บอยู่ที่ `~/.gemini-code/chrome-profile/` ซึ่งเป็นโปรไฟล์ Chrome แยกจากของที่ใช้อยู่ประจำ
> ไม่ได้อยู่ใน repo แต่ละคนที่โคลนไปใช้จึงลงชื่อเข้าใช้ด้วยบัญชี Google ของตัวเอง

## โหมดเว็บ

```bash
cd ~/some-folder    # รูปที่ Gemini สร้างจะถูกเซฟในโฟลเดอร์นี้
gcode               # เปิดแชทใหม่ (terminal ใหม่ = แชทใหม่)
gcode "แปลคำว่า hello เป็นภาษาญี่ปุ่น"   # ถามครั้งเดียวแล้วออก
```

- ครั้งแรก `gcode` จะเปิด Chrome **โปรไฟล์แยก** (`~/.gemini-code/chrome-profile`) ให้ลงชื่อเข้าใช้ Google หนึ่งครั้ง
  ครั้งต่อไปจำการล็อกอินไว้ Chrome ปกติของคุณไม่ถูกแตะต้อง
- แต่ละ `gcode` เปิดแท็บของตัวเองในหน้าต่างนั้น และปิดแท็บเมื่อออก (แชทยังอยู่ในประวัติ Gemini)
- Chrome ทำงานแบบ**ซ่อน** ไม่เด้งขึ้นมาและไม่แย่งโฟกัส จะโชว์เฉพาะตอนต้องล็อกอิน หรือเมื่อพิมพ์ `/open`
  (ถ้าเปิดดูด้วย `/open` แล้ว หน้าต่างจะโชว์ค้างไว้จนกว่าจะซ่อนเอง ด้วย Cmd+H)
- รูปที่ Gemini สร้างจะถูกดาวน์โหลด**ขนาดเต็ม**มาเซฟเป็น `gemini_วันที่_เวลา_ลำดับ.jpeg` ในโฟลเดอร์ที่เรียก gcode
  ถ้าดาวน์โหลดขนาดเต็มไม่ได้ จะเซฟขนาดพรีวิวแทนและบอกไว้

คำสั่ง: `/help` `/new` (แชทใหม่) `/mode [ชื่อ]` (เช่น `/mode 3.1 Pro`, `/mode flash`) `/open` (ดูแท็บใน Chrome)
`/close` `/exit` (ออกโดยเก็บแชทไว้)
กด Ctrl+C ระหว่างรอ = หยุดคำตอบ

**`/close`** ลบแชททุกอันที่ terminal นี้สร้าง (รวมแชทที่เปิดด้วย `/new`) ออกจาก Gemini แล้วค่อยปิด terminal
- ลบฝั่ง Gemini ก่อน และตรวจซ้ำว่าแชทหายจริง ถ้าลบไม่สำเร็จจะ**ไม่ปิด** terminal และแจ้ง error
- การปิด terminal ทำผ่านฟังก์ชัน `gcode` ใน `~/.zshrc` (แอปออกด้วย exit code 99 → ฟังก์ชันสั่ง `exit` ให้ shell)
  ถ้าเรียก `./gcode` ตรงๆ แอปจะลบแชทแล้วบอกให้ปิดหน้าต่างเอง

**ข้อควรรู้**
- การควบคุมเว็บ Gemini ด้วยสคริปต์ขัดกับแนวทางการเข้าถึงอัตโนมัติของ Google มีความเสี่ยงที่บัญชีจะถูกจำกัด ใช้อย่างพอประมาณ
- ถ้า Google เปลี่ยนหน้าเว็บ แอปอาจพัง: selector ทั้งหมดรวมไว้ด้านบนของ `gemini_code/web.py` ให้แก้ที่เดียว
- selector อิงหน้าเว็บภาษาไทย (`?hl=th`)
- ยังไม่มี: แนบไฟล์/รูปจาก terminal, ดึงรูปที่ไม่ใช่รูปที่ Gemini สร้าง (เช่นรูปจากผลค้นหา), แสดงคำตอบทีละคำ

## โหมด API

```bash
cd ~/some-project      # agent จะทำงานในโฟลเดอร์ที่คุณเรียกใช้
gcode --api            # โหมดคุยต่อเนื่อง
gcode --api "อธิบายโปรเจกต์นี้"  # ทำงานเดียวแล้วออก
gcode --api -m gemini-2.5-flash  # เลือกโมเดล
gcode --api --yolo     # อนุมัติทุกอย่างอัตโนมัติ (ระวัง)
```

คำสั่งในแอป: `/help` `/clear` `/model [ชื่อ]` `/models` `/usage` `/exit`
เวลาถูกถามอนุญาต: `y` = ครั้งนี้, `a` = อนุญาต tool นี้ตลอดเซสชัน, `n` = ไม่ (บอกเหตุผลให้ Gemini ได้)

ถ้าโปรเจกต์มีไฟล์ `GEMINI.md` หรือ `AGENTS.md` จะถูกโหลดเป็นคำสั่งเพิ่มเติมให้ agent อัตโนมัติ

`/usage` แสดงจำนวนคำขอและ token ของเซสชันนี้ และจำนวนคำขอของวันนี้แยกตามโมเดล
(บันทึกใน `~/.gemini-code/usage.json` นับวันตามเวลาแปซิฟิกซึ่งเป็นเวลาที่โควตารายวันรีเซ็ต
คือประมาณ 14:00–15:00 น. เวลาไทย) โควตาที่เหลือจริงดูได้ที่ https://aistudio.google.com/usage

**โควตาที่เหลือ** = เพดาน − ที่ใช้ไป เพราะ Google ไม่มี API บอกโควตาที่เหลือ
- เพดานโดยประมาณอยู่ใน `limits.json` (แก้ให้ตรงกับหน้า Rate limits ใน AI Studio ได้)
- เมื่อเจอ error 429 แอปจะอ่านเพดานจริงที่ Google แนบมา บันทึกใน `~/.gemini-code/limits.json` และใช้แทนค่าประมาณ

### เครื่องมือที่ Gemini ใช้ได้

| tool | ทำอะไร | ต้องขออนุญาต |
|---|---|---|
| `read_file` | อ่านไฟล์ (มีเลขบรรทัด) | ไม่ |
| `list_dir` | ดูไฟล์ในโฟลเดอร์ | ไม่ |
| `glob_files` | หาไฟล์ตาม pattern เช่น `**/*.py` | ไม่ |
| `grep` | ค้นหาข้อความด้วย regex | ไม่ |
| `write_file` | สร้าง/เขียนทับไฟล์ (แสดง diff ก่อน) | ใช่ |
| `edit_file` | แทนที่ข้อความในไฟล์ (แสดง diff ก่อน) | ใช่ |
| `run_shell` | รันคำสั่ง shell | ใช่ |

### ข้อจำกัดของโหมด API

- **โควตาฟรีน้อย**: ประมาณ 10–15 คำขอ/นาที งานหนึ่งอาจใช้หลายรอบ ถ้าโดน 429 แอปจะรอแล้วลองใหม่ให้เอง
  ถ้าโควตารายวันหมดจะแสดง error ให้รอวันถัดไปหรือเปลี่ยนโมเดล (`/models` ดูรุ่นที่ใช้ได้)
- ข้อมูลที่ส่งผ่าน key ระดับฟรี Google อาจนำไปพัฒนาโมเดล อย่าใช้กับโค้ดที่เป็นความลับ
- ยังไม่มี: streaming คำตอบทีละคำ, บีบอัดบทสนทนาเมื่อยาวมาก (ใช้ `/clear` แทน), บันทึก/เรียกเซสชันเก่า,
  undo การแก้ไฟล์ (ใช้ git ในโปรเจกต์เป็นตัวช่วย)
- `run_shell` รันแต่ละคำสั่งใน shell ใหม่ ดังนั้น `cd` ไม่คงอยู่ข้ามคำสั่ง

## เรียกจากสคริปต์ / จาก Claude Code

โหมด one-shot (`gcode "คำสั่ง"`) จบแล้วออกทันที จึงมีธงสำหรับผูกแชทที่สร้างไว้กับ "session" ของผู้เรียก
เพื่อให้ process อื่นกลับมาคุยต่อหรือลบแชทนั้นได้ ข้อมูลเก็บที่ `~/.gemini-code/sessions/<key>.json`

| ธง | ทำอะไร |
|---|---|
| `--session KEY` | จดแชทที่รันนี้สร้าง ไว้ใต้คีย์ KEY |
| `-c`, `--continue` | คุยต่อในแชทล่าสุดของ `--session` (ถ้าแชทถูกลบไปแล้วจะเปิดแชทใหม่ให้) |
| `--resume CHAT_ID` | คุยต่อในแชทที่ระบุ |
| `--list-chats` | แสดงแชทของ `--session` เป็น JSON (`id`, `prompts`, `created_at`, `updated_at`) |
| `--chats` | แสดงแชทที่มีอยู่แล้วใน Gemini (ชื่อ + id) เพิ่ม `--json` เพื่อเอาไปใช้ต่อ |
| `--chat CHAT_ID` | เข้าไปคุยต่อในแชทที่มีอยู่แล้ว **ไม่นับเป็นแชทของ gcode** จึงไม่ถูกลบ |
| `--delete CHAT_ID ...` | ลบแชทตามรหัสที่ระบุ เว้นจังหวะระหว่างการลบให้เอง |

```bash
gcode --session "$CLAUDE_CODE_SESSION_ID" -c "สร้างรูปโลมาให้หน่อย"
gcode --session "$CLAUDE_CODE_SESSION_ID" --list-chats
gcode --session "$CLAUDE_CODE_SESSION_ID" --delete 1a2b3c4d
```

คำสั่ง `/gcode` และ `/gcodeclose` สำหรับ Claude Code อยู่ใน `commands/` ของ repo นี้ และ setup.sh
ลิงก์เข้า `~/.claude/commands/` ให้แล้ว (`git pull` ที่นี่จึงอัปเดตคำสั่งไปด้วย)

> **⚠️ ไฟล์คำสั่งสองไฟล์นี้มีอีกก๊อปปี้อยู่ที่ repo `wannuwat-s/claude-config` (`commands/`)**
> ตั้งใจให้ซ้ำกันเพื่อให้โคลน repo เดียวก็ใช้ได้ **แก้ที่ไหนต้องคัดลอกไปทับอีกที่เสมอ**
> ไม่งั้นเครื่องที่ลิงก์คนละ repo จะทำงานไม่เหมือนกัน (มีโน้ตเตือนไว้ในหัวไฟล์ทั้งสองที่แล้ว)

| คำสั่ง | ทำอะไร |
|---|---|
| `/gcode <สิ่งที่อยากให้ทำ>` | ส่งเฉพาะข้อความนั้นไปให้ Gemini แล้วเอาคำตอบกลับมา ครั้งถัดไปคุยต่อในแชทเดิม |
| `/gcode --new <...>` | บังคับเปิดแชท Gemini ใหม่ |
| `/gcode --chats` | แสดงแชทที่มีอยู่แล้วใน Gemini ให้เลือก |
| `/gcode --chat <เลข\|ชื่อ\|id> <...>` | ส่งเข้าแชทที่มีอยู่แล้ว |
| `/gcodeclose` | ลบแชท Gemini ที่แชท Claude นั้นสร้าง โดยถามยืนยันก่อนเสมอ |

ทั้งคู่ใช้ `$CLAUDE_CODE_SESSION_ID` เป็นคีย์ แชท Gemini จึงผูกกับแชท Claude ที่สั่งเท่านั้น
`--delete` ลบเฉพาะรหัสที่ส่งเข้าไป ไม่เคยอ่านรหัสจาก URL ปัจจุบัน

### แชทที่ไม่ได้สร้างเอง จะไม่ถูกลบ

`--chat` และ `/resume` แค่เข้าไปคุยต่อในแชทที่มีอยู่แล้ว gcode จะเก็บ id พวกนี้ไว้คนละที่กับแชทที่ตัวเองสร้าง
(`attached` แทนที่จะเป็น `chat_ids`) `/close`, `/gcodeclose` และ `--delete` จึงไม่มีทางไปลบแชทของเจ้าของ
และจะไม่สอน @@ protocol ใส่แชทเหล่านั้นด้วย เพราะเป็นบทสนทนาที่มีอยู่ก่อนแล้ว

## โครงสร้างโค้ด

```
gemini_code/
  __main__.py   จุดเริ่ม: เลือกโหมด, หน้าจอโหมด API, slash commands
  web.py        โหมดเว็บ: เปิด Chrome, ส่งข้อความ, รอคำตอบ, แปลงเป็น markdown, เซฟรูป
  agent.py      โหมด API: ส่งบทสนทนา → Gemini ขอเรียก tool → ขออนุญาต → รัน → ส่งผลกลับ
  tools.py      นิยามและโค้ดของแต่ละ tool (เพิ่ม tool ใหม่ได้ที่นี่)
  usage.py      นับการใช้งานและโควตา (โหมด API)
  prompt.py     รับข้อความจาก terminal
  sessions.py   จดแชทที่แต่ละ --session สร้าง (~/.gemini-code/sessions) ให้ process อื่นคุยต่อ/ลบได้
commands/       /gcode และ /gcodeclose สำหรับ Claude Code (setup.sh ลิงก์เข้า ~/.claude/commands)
gcode           launcher เรียกได้จากทุกโฟลเดอร์
setup.sh        ติดตั้ง venv + dependencies + ลิงก์คำสั่ง
```
